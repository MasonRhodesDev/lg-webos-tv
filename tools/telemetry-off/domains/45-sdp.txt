# LG Service Delivery Platform (SDP). Router parents: lgtvsdp.com nextlgsdp.com tvsdp.lgeapi.com ibs.lgappstv.com ibsstat.lgappstv.com
#
# One hostname per line; '#' starts a comment. telemetry-off.sh maps every
# name to 0.0.0.0 and :: in a bind-mounted /etc/hosts. Hosts files have no
# wildcards, so the router-side block (docs/telemetry.md, "Network-side
# verification") should use the parent domains listed in each file's notes.
#
# Sources:
#   [fw]   found on webOS TV 4.10.0 / 05.40.45 (strings in the rootfs, or the
#          TV's own caches); evidence in docs/telemetry.md
#   [lgws] from Life's Good Without Spying (MIT, (c) 2026 Lewis Wood),
#          https://github.com/lewisdoesstuff/lifesgoodwithoutspying
#          app/init/blocklist.d/45-sdp.txt at commit 8c42711
#
# sdx (the on-demand com.webos.service.sdx) is the TV's single SDP client:
# device auth, EULA sync, the app store, ACR config (sdp_check_acr), and the
# rdx upload URL. webOS 4.x uses lgtvsdp.com; webOS 5+ uses nextlgsdp.com.
#
# Breaks: LG Content Store, app install/update, LG account, EULA/notice
# sync, LG Channels guide. LGWS notes webOS 5+ sets the clock from SDP's
# X-Server-Time; this firmware ships AllowNTPTime=false, so the clock is
# kept by the standby micom RTC while the TV stays plugged in.
